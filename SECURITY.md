# Security Policy

Please report any vulnerabilities or potential security incidents privately to
both <donn@fossi-foundation.org> and <leo@fossi-foundation.org>.

We do not currently consider issues that allow text-format configuration files
such as JSON or YAML to achieve arbitrary code execution to be security
incidents as they doubtlessly exist. Nonetheless, we would like to address them
in the future and would appreciate public bug reports about them.
